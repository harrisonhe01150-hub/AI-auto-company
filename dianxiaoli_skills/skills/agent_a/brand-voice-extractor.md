**目的**：给这家店定一个固定的说话方式，写进语气卡；以后排期、写帖、做轮播都照这张卡来。

**输入**
- 这家店最近 20–50 条历史帖子（文案 + 表现数据，有就带上）
- 最近 30 天的买家对话样本（脱敏后）——买家怎么称呼这家店、常问什么、老板怎么答
- 老板一句话描述自己的店（有就用，没有就从对话里推）

**做法**
1. 从历史帖和对话里找重复出现的说法：常用词、句式、称呼方式、是否用表情、中英混用程度。
2. 判断这家店的三个定位维度：**价格感**（走量便宜 / 品质中端 / 精品）、**关系感**（熟人档口 / 专业供应商 / 潮流买手）、**语言**（中文 / 英文 / 双语 / 当地语言）。
3. 找出**不该说的话**：老板从不用的词、历史上表现最差的那类帖子的共同点。
4. 写成语气卡。

**输出：语气卡**
```
店名：
一句话人设：（例：约堡华商圈里最靠谱的女装批发档口，货实价实）
价格感 / 关系感 / 语言：
常用词（5–8 个）：
句式习惯：（短句/长句、是否带问句、结尾方式）
表情使用：（不用 / 偶尔一个 / 常用哪几个）
禁用词：
参考范例（从历史里挑 2 条最像的帖子原文）：
```

**验收**：拿语气卡给不了解这家店的人看，他能用它写出一条老板看了会说「像我」的帖子。做不到就是卡写虚了，回去补具体词和范例。

**红线**：语气卡里不放任何买家个人信息；对话样本用完即弃，不入库。
