**目的**：复盘只回答一个问题——**上周哪类帖子带来了后来成交的买家。** 点赞和浏览只作参考，不作结论。

**输入**
- 上周发帖列表（日期 / 类型 / 款号 / 形式）
- 归因数据：AI 问买家「你是在我们的帖子上看到的吗」记下的答案，以及每个新询盘的首次触达时间
- 台账：上周新询盘中哪些成了订单、哪些转人工、哪些流失
- 平台自带数据（浏览 / 保存 / 私信数），有就用

**做法**
1. 把每个新询盘挂到最可能的那条帖子上：买家自己说了就按他说的；没说的按「询盘时间在帖子发出后 48 小时内 + 问的是那条帖的款号」归。挂不上的记为「非内容来源」。
2. 按帖子类型汇总四个数：帖子数、带来的询盘数、其中成交数、成交金额（金额只给老板看，不写进公开材料）。
3. 算每类的**询盘成交率**（成交 ÷ 询盘）。这是唯一排序依据。
4. 找出本周最好和最差的单条帖子，各写一句「为什么」——只写能看出来的事实（款、图、时间、钩子），不猜。
5. 给下周计划三条建议：加什么、减什么、试什么。「试什么」每周只提一个新变量，方便下周看得出效果。

**输出**
```
## 上周复盘（日期范围）
| 类型 | 帖子数 | 询盘 | 成交 | 询盘成交率 |
最好的一条：（款号 + 一句原因）
最差的一条：（款号 + 一句原因）
下周建议：加 / 减 / 试（各一句）
未归因询盘：N 条（占比）
```

**红线**：复盘里不出现买家个人信息；成交金额只进老板端，不进任何对外内容。归因挂不上就写「未归因」，不要硬挂。
