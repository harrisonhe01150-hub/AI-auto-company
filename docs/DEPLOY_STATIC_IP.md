# 企微可信 IP 老是失效？给 Railway 配固定出口 IP

## 为什么每次部署完机器人就哑了

企业微信「微信客服」要求把服务器的**出口 IP** 填进可信 IP 白名单，不在名单里的请求一律拒。
Railway 默认不保证出口 IP 固定：每次 deploy（改代码、改环境变量、平台自己迁容器）都可能换一台机器，
出口 IP 就变了。企微那边还是旧 IP → 调接口全被拒 → 表现就是「消息进来了，小力不回」。

## 现在的手工救火（能用，但每次部署都得来一遍）

1. 浏览器打开 `https://你的域名/egress?key=你的BOSS_KEY`，拿到 `railway_egress_ip`。
2. 企业微信管理后台 → 应用管理 → 微信客服 → 找到「店小力AI店员」应用。
3. 「企业可信 IP」里把新 IP 追加进去（多个 IP 用英文分号 `;` 分隔），保存。
4. 回微信发一条测试消息，确认能回。

老名单里的死 IP 可以顺手删掉，但别删到别的服务在用的。

## 一劳永逸：开 Railway 的固定出口 IP

Railway 有「静态出口 IP」这类能力（菜单名各版本会变，**在 Settings → Networking 一带找
Static Outbound IP / Static Egress IP / Enable Static IPs 之类的开关**）。大致步骤：

1. Railway 控制台 → 选中这个 Service（不是 Project 根）。
2. 进 **Settings** → 找 **Networking** 分组。
3. 在这一带找静态出口 IP 的开关，打开它。
   - 这项能力通常要**付费计划**才有；如果界面上找不到或提示需要升级，先看账号计划。
   - 具体名称、位置以当时界面为准，本文不保证一字不差。
4. 打开后 Railway 会给出一个（或一组）固定 IP，把它们**一次性**全部填进企微可信 IP。
5. 重新 deploy 一次，再访问 `/egress?key=…` 核对：返回的 IP 应该就是那组固定 IP 之一。

配好之后再部署就不用动企微了。

## 排查小抄

- `/egress` 报 error：容器出网有问题，先看 Railway 服务是不是活着。
- IP 已经加了还是不回：确认改的是「微信客服」那个应用的可信 IP，且分隔符是英文分号。
- 有多个固定 IP：**全部**都要填，Railway 可能从其中任意一个出去。
