# 让新单自动发到您的群里

配好之后，买家一下单、一发付款截图、一要找您，群里马上就有消息，不用再自己开网页看。
一共三步，五分钟。

## 第一步：在企业微信里建群、加机器人

1. 企业微信里拉一个群（就您自己也行，建议把店里管事的一起拉进来）。
2. 点群右上角「…」→ 群机器人 → 添加 → 新创建一个，名字随便起，比如「店小力」。
3. 创建完会给您一个 **Webhook 地址**，长得像 `https://qyapi.weixin.qq.com/...key=xxxx`。
   点「复制」。

> 这个地址等于钥匙：谁拿到谁就能往您群里发消息。别转到别的群，别发朋友圈，别截图给人看。
> 万一发出去了，在同一个地方把机器人删掉重建一个，旧地址立刻作废。

## 第二步：把地址填进后台

打开 Railway → 您的店小力项目 → Variables，新建一条：

- 名字：`BOSS_WEBHOOK`
- 值：刚才复制的那串地址

保存。

## 第三步：重新部署

Railway 会自动重启。等一两分钟就生效了。

## 另一种方式：直接发到您的企业微信（不用建群）

想让消息直接进您自己的企业微信聊天框、不建群，就配这个。一次配好，长期有效。

1. 电脑打开企业微信管理后台 → **应用管理** → 自建 → **创建应用**，名字写「店小力」，随便传个图标。
2. 建完点进去，记下 **AgentId**（一串数字）和 **Secret**（点「查看」，会发到您的企业微信里）。
3. 同一页的**可见范围**，把您自己加进去（要收消息的人都得在里面）。
4. 后台 → 通讯录 → 点您自己 → 看**账号**那一栏，那串就是要填的 userid（不是手机号、不是姓名）。
5. Railway → Variables，新建三条：`WECOM_AGENT_ID`（AgentId）、`WECOM_AGENT_SECRET`（Secret）、
   `BOSS_WECOM_USERID`（您的账号；要发给几个人就用 `|` 隔开，比如 `zhangsan|lisi`）。
6. 保存，等它重新部署一两分钟，就生效了。

- 两种可以**同时开**：群里和您个人都会各收到一份。
- 只开这条就**不用建群**了，`BOSS_WEBHOOK` 可以不填。
- 您用个人微信「互通」登录企业微信也能收到，只是微信那头看到的是纯文本，内容一样全。
- 这条通道没有「48 小时不说话就发不了」的限制。

**收不到怎么办**：打开 `您的网址/status` 看 `boss_notify`——
`channels` 里能看出到底开了哪条（`webhook` 是群、`app` 是应用消息）；
`last` 里的 `why` 要是写着「这些人没收到」，就是第 4 步的账号填错了，回去照抄一遍。

## 配好之后群里会收到什么

- **🧾 新单待核准 #12** —— 张三 ｜ A3保温壶500ml ×60 ¥1,920，下面一行告诉您回「核准12号」就行
- **💳 付款截图待核对 #13** —— 买家发了付款图，等您对账
- **⚠️ 金额对不上 #14** —— 截图金额和订单对不上，您来定
- **🙋 买家要找老板 #15** —— 投诉、退换、买家点名要人
- **📵 没能回告买家** —— 您核准了，但买家超过 48 小时没说话，微信不让我们主动发；
  群里会把原话给您，您复制一下手动发给买家
- **每天的质检日报和每周的周报**

一分钟内消息太多时（超过 18 条），剩下的会攒起来并成一条「⏳ 积压 N 条」发出来，不会丢。

## 收不到消息怎么办

浏览器打开 `您的网址/status`，找 `boss_notify` 这一段：

- `configured` 是 `false` → 变量没填对或者没重新部署，回第二步
- `configured` 是 `true` 但 `failed` 在涨 → 看 `last` 里的 `why`，多半是地址复制错了或机器人被删了，重建一个再填一次

两条都没配（或都发不出去）的时候，一切照旧：消息还是像以前一样发到您的微信客服里。
