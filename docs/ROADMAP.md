# 店小力 · 产出路线 v3（2026-09-04 起）

一个底座，两条线。所有工程产出优先服务线 B（自有线），线 A（度小满线）要的东西和线 B 共用 80% 代码，签约当天直接接上。

| | 线 A · 度小满线（加速器） | 线 B · 自有线（底牌，现在做） |
|---|---|---|
| 服务谁 | 度小满 800–1,000 万小微客群中的批零商户 | ① 义乌档口 ② 义乌/浙苏工厂 ③ 海外华商 & 本地商户 |
| 主打产品 | 大众版小程序（低价铺量，每家一个数据节点） | 定制版 / 工厂版（高客单），大众版随后 |
| 收入 | 商户订阅 + 按数据节点向度小满结算 | 订阅 + 部署费 + 大客户佣金 |
| 依赖 | 合作协议签了才能导流和联调 | 只依赖自己和家里的资源 |

| L1 微型（月流水 <3 万 / SKU <100） | ¥200–300/月 | — |
| L2 小型（3–10 万 / 100–300） | ¥400–600/月 | — |

### 序 2 工厂行业包 v1 · 明细

| # | 项 | 说明 |
|---|---|---|
| 2.1 | FOB 阶梯报价矩阵 | 数量档 × 港口（宁波 / 义乌 / 上海 / 深圳）× 币种；价格由代码算，AI 只措辞 |
| 2.2 | MOQ / 打样 / 交期 | 起订量判定、样品单流程（样品费、寄样、确认）、交期按数量档回复 |
| 2.3 | 规格图分流 | 图片三分流加第四路：规格图 / 图纸 → 转工程 + 记录，不报价 |
| 2.4 | 报价单生成 | 询盘成交前一键出 PDF 报价单（E 商务助理并入此处，不单独立项） |
| 2.5 | **发货单号推送** | 老板回「17 发货 SF1234567」→ 系统把物流单号推给买家 + 台账记录。补上核准回告里「发出后我把单号发您」这句一直没兑现的承诺；档口版同样受益 |
| 2.6 | 演示店 | 用试点工厂的真实产品表（`stock_xlsx_importer`）搭演示店，他爸扫码用英文问的是自家的货 |
| 2.7 | 工厂销售技能包 | `skills/agent_b/factory-*.md`：外贸询盘话术、打样话术、交期话术；过门禁后装 |
| 2.8 | 工厂场景断言 | `testing/scenarios_factory_v1.yaml` ≥20 条，门禁扩到 48+ |

从 POD ERP 报价单里借的只有 2.5 一条；排产 / PDA / 跑图 / 一物一码明确不做。工厂没有 ERP 的，后续可加「工单状态板」（三五个状态，网页控制台 + 微信一句话更新）——是记账的延伸，不是排产系统。
